# Contribution guidelines

Thanks for helping make this list better! To add a project, open a pull request that edits `README.md` (English) and, if you can, `README.es.md` (Spanish). If you only edit the English list, a maintainer will add the Spanish translation.

- The project must be related to Mostro: a client, a tool, a library, a service, documentation or a resource built for or around it.
- Add one item per line, in the section that fits best, in this format:

  ```markdown
  - [Name](https://link) is a short description of what it does.
  ```

- If the project has a live site and a separate repository, link the site and add the repository as `([source](https://github.com/...))`.
- Keep descriptions short, in English, and without marketing language.
- Check that the links work and that the project isn't already listed.
- Move projects that are no longer maintained to the **Archived** section.
- Use one pull request per project, with a title like `Add <project>`.
